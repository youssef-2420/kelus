# Kelus — GitHub upload guide

The homepage is `app/page.tsx`. In Next.js App Router projects, this file is the equivalent of `index.html`.

## Main files

- `app/` — all website pages
- `components/` — reusable interface pieces
- `lib/demo-data.ts` — example product data
- `public/` — images and icons
- `app/globals.css` — styling for the whole site

## Start locally

```bash
npm install
npm run dev
```
