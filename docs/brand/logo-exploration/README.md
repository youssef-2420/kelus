# Kelus logo exploration

Open [index.html](./index.html) to compare seven editable, one-color SVG concepts. The page previews each mark at 16px and 32px and on paper, Kelus green, and ink backgrounds.

**Selected:** `07-recall-k.svg`. Its continuous return stroke pairs the name's K with Kelus's revision loop. The site uses it beside the existing wordmark in the header, footer, and course rail, and as the browser and touch icon.

The remaining six marks are retained as visual explorations. These assets have not been trademark-cleared.

`07-recall-k-1024.png` is a transparent green PNG export of the selected mark. The SVGs use `currentColor` so the implementation can use the same geometry on light and dark surfaces.
