# Kelus logo exploration

Open [index.html](./index.html) to compare seven editable, one-color SVG concepts. The page previews each mark at 16px and 32px and on paper, Kelus green, and ink backgrounds.

**Recommendation:** `01-margin-k.svg`. It remains legible at favicon scale and can sit beside the existing Kelus wordmark without turning the mark into a diagram of the whole product. `07-recall-k.svg` is a softer alternative; `05-route-k.svg` speaks more directly to the routing system.

The existing live wordmark and favicon have **not** been replaced. These are visual proposals, not trademark-cleared assets. Once a direction is chosen, refine optical spacing, create final light/dark lockups and favicon exports, then update the site in one controlled change.

`01-margin-k-1024.png` is a transparent green PNG export of the recommended mark. The SVGs use `currentColor` so the final implementation can use the same asset on light and dark surfaces.
